# 项目定位

- 项目名称：面试练习室 · AI 技术面试助手。
- 当前正式版本：V1（Release）。
- 质量要求：标准级（Quality Profile：Standard）。
- 产品定位：面向个人开发者的本地文本技术面试训练工具，围绕岗位、简历和项目进行动态追问与复盘。
- 目标用户：准备 Java 后端、大模型应用 / Agent 开发等岗位面试的个人用户。

V1 已交付。现有功能范围以 [需求背景](releases/v1/PROJECT_BRIEF.md) 和 [产品行为规范](releases/v1/SPEC.md) 为准；V2 五项范围及评审建议已批准并实施，软件验收和真实质量分开记录，见 [V2 验证记录](releases/v2/VERIFICATION.md)。正式交付尚未切换为 V2。

## 运行与发布边界

应用仅供一个人在本机使用。调用真实模型时，相关资料与对话会发送到用户指定的模型服务。密钥和个人资料保存在本地、已设置为不提交 Git 的目录中。

用户曾授权在 GitHub 创建公开代码仓库并同步 `main`。仓库地址和具体授权范围见 [决策与授权记录](DECISIONS.md)。这项授权不包含应用公网部署、创建 PR、Tag 或 GitHub Release；后续操作仍按对应授权执行。

2026-10-16 最新交付边界：用户已授权测试所需真实模型调用及提交、推送。五项开发和本轮固定样本校准已完成，保留两次历史结构失败、提示词修正及复验结果；代码同步供用户人工验收，整体证据仍为 PARTIAL，正式版本仍 V1。人工验收服务使用独立合成目录，不迁移个人真实库。
