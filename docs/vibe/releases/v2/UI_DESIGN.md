## 导航：一个一级入口，六项局部工具

采用方案 2：将六项训练工具收拢到“专项训练”。侧栏维持五项主入口；仅进入专项模块时，在内容顶部显示工具导航。历史、报告、资料库、面试配置及答题页不显示该工具导航，避免误认为当前页面的筛选条件。

| 一级入口（按顺序） | 保持的地址 | 归属范围 |
|---|---|---|
| 练习概览 | `/` | 首页 |
| 开始面试 | `/configure/quick` | `/configure/*`、`/sessions/:id` |
| 专项训练 | `/review` | 以下六项工具及其详情 |
| 个人资料库 | `/materials` | 既有资料库 |
| 面试历史 | `/history` | 历史列表、`/reports/:id` |

| 专项工具 | 保持的地址 | 详情页末级面包屑 |
|---|---|---|
| 错题复习 | `/review` | 复习详情 |
| 能力看板 | `/skills` | 当前只有看板页 |
| 原题重练 | `/practice` | 作答详情 |
| 岗位诊断 | `/jd-diagnostics` | 诊断详情；`/sprints/:id` 显示训练清单 |
| 项目经历 | `/stories` | 经历详情；保留个人介绍和 STAR 等原有内容 |
| 系统设计 | `/design-practice` | 训练详情 |

列表和详情均同时标明一级模块与当前工具。归属由当前路由计算，直接打开、刷新、返回均保持，不依赖点击记忆。面包屑不再显示无落点的“我的空间”：例如“专项训练 → 岗位诊断 → 训练清单”“面试历史 → 面试复盘”；父级使用原生链接返回已有列表。链接保留真实 href、修饰键和新标签行为。用于展示判断的路径兼容大小写及末尾斜杠，不改写实际 URL。

V2 关闭时，原 App 仍只有练习概览、开始面试、个人资料库、面试历史四项入口。专项入口通过命名插槽由 V2 壳提供，不改变 AppLayout 原有三个 Props。

## 侧栏每日一句（2026-10-18）

按用户要求，将共用侧栏底部的静态说明改为“每日一句”，沿用当前浅色侧栏和分割线；V1、V2、V3 复用同一组件。仅新增前端展示交互，不改后端、业务状态、接口或原导航。

- 内置 12 条技术面试提醒，围绕表达、方案权衡、坦诚推演、项目细节和复盘；分类是提醒主题，不虚构作者或引用。
- 按本机年月日计算固定索引，同一天重新打开或刷新保持初始句子；本机跨日后重新打开使用新日期。不使用 UTC 日期，不增加计时器。
- “换一句”只更新当前页面的展示偏移量，循环浏览内置内容；刷新恢复当天初始句子，不请求网络、不调用模型、不读写浏览器存储。
- 正文 15px／1.85；按钮与隐私说明入口至少 44px，支持键盘。换句使用 180ms 淡入淡出，并遵循系统减少动态效果的偏好；预留正文高度，减少切换时的位置跳动。
- 底部保留“本地私人空间”，通过原生折叠说明展示“资料与记录保存在本机。真实练习使用你配置的模型服务。”，不暗示模型调用全部在本机完成。
- 820px 以下沿用原侧栏底部区域隐藏规则；桌面高度不超过 760px 时收紧侧栏留白，更矮窗口可在侧栏内部滚动，不截断内容。

## 层级、字号与窄屏

应用壳及专项导航使用 Operate 模式，以清楚定位和快速切换为主。桌面主导航 16px，操作区域至少 48px；专项标题 20px、工具入口 16px，以细分割线和蓝色下划线标记当前项。面包屑 14px。沿用浅色冷中性底、深色正文与蓝色重点，不引入渐变或装饰动效。

820px 以下主导航为局部横向滚动行，字号 14px、操作区域至少 44px；专项工具保持 16px、单行局部横向滚动，600px 以下至少 44px。面包屑可换行，窄屏状态区另起行，内容边距同步现有页面断点。长标题完整换行，不以压小字号解决拥挤。

## 复盘 C 方案：先读答案，再看辅助信息

用户于 2026-10-16 选择 C“评阅手册”并批准实施。报告采用 Read 模式：逐题原答、分类分析、回答思路与知识解释为主文；岗位、概览、评分、整理复习、原题重练与完整对话为辅助内容。保留原内容、分类、原生 details/summary 和业务动作。

- 报告标题桌面 32px、手机 30px，题目 24px，正文 20px／1.8，辅助说明 16px／1.8。预格式原答及解释最大行宽 72ch，长单词与路径自然换行。
- 桌面主文加右栏，右栏 340px、间距 32px；1280px 以下收紧为 300px／24px；1100px 以下单列，先主文再辅助内容。
- 报告工具通过既有插槽进入辅助区，原问题选择、整理复习、原题重练、来源返回与专项练习事件保持；加载、错误、无答案及生成中条件不变。
- 2026-10-17 按用户要求，将逐题分析的“资料不足，无法判断”改为“表述存疑 / 建议补充技术细节”，保留原圆点。有该类条目时，在标题下、条目前显示“你表达的核心方向正确，但以下语句较为口语化，面试官可能产生技术怀疑：”；空态不显示引导。引导沿用正文 20px／1.8。仅调整展示文案，原 `uncertain` 字段、分类、模型结果及接口不变。
- 本次导航改造后，报告页不再显示六项训练工具，因此删除原先只针对报告手机页的工具栏样式覆盖。
