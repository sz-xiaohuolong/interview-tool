工程与浏览器检查使用独立合成目录、显式 Mock 和本机 HTTP 测试替身。2026-10-16按初次与后续授权分批发送19次真实模型请求，历史停止及修正见第9、11节，内置浏览器真实链路见第12节。没有读取或操作个人数据库、没有发送真实个人资料；用户已授权提交与推送，供其人工验收，部署和PR未执行。

实际命令（在仓库根目录执行）：

```bash
JAVA_HOME=$(/usr/libexec/java_home -v 21) ./scripts/test.sh
JAVA_HOME=$(/usr/libexec/java_home -v 21) bash scripts/e2e.sh \
  --config=playwright.v2.config.ts --global-timeout=180000
```

工程使用 Java 21.0.8、Spring Boot 3.5.9、SQLite JDBC 3.49.1.0、Vite 6.4.4、Vue Router 4.6.4。沿用已有依赖锁，不升级项目依赖。Node 使用项目既有 `.runtime/node_modules/node/bin` 运行时。浏览器脚本不读取 `.env.local`，将 Key 置空、provider 明确设为 mock；独立临时目录在退出时清理。后端测试使用各自的合成临时目录。

最新完整工程日志为本机 `.evidence/v2/story-prompt-revision/engineering.log`；15项自动浏览器日志为 `.evidence/v2/e2e-version-closure.log`。旧日志保留排障历史，不相加为测试总数，不以早期失败覆盖后续适用结果。

## 5. 本地启用、关闭与数据边界

V2 默认关闭，本轮没有改 `.env.local` 来启用 V2，也没有启动用户个人库的 V2。合成浏览器环境由新 Playwright 配置调用维护迁移脚本后启用。

```bash
python3 scripts/migrate-v2.py \
  --data-dir /absolute/path/to/chosen-data \
  --backup /absolute/path/to/new-backup-directory \
  --confirm-maintenance
```

迁移后用 `DATA_DIR` 选择同一目录，以 `V2_ENABLED=true` 或 Spring 属性 `app.v2.enabled=true` 开启；未迁移而开启会拒绝启动。日常入口仍是 `./scripts/dev.sh`，须使用 Java 21。该脚本会 source `.env.local`，其中已有变量可能覆盖调用时的同名变量，因此不能只靠外层环境变量假定数据和模型已隔离；真实启用前应核对实际配置，但不得将密钥打印进日志。

关闭时停止相关进程，设 `V2_ENABLED=false` 并检查没有更高优先级的 app.v2.enabled=true，再重启。新增表和历史保留；前端回到原 V1 入口，V2 写 API 拒绝。需要恢复备份时另行明确授权，停止进程、另存当前目录，再替换完整目录；备份后所有写入将不可见。不直接覆盖主数据库，不提供自动删表降级。
