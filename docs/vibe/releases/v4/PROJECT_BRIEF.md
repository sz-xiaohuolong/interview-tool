## 目标与范围

1. 新增“快速练习”：选择岗位和3/5/8道主问题，默认5题；岗位支持Java后端、Agent开发和自定义。职级默认初级，折叠设置可改。不要求资料，不经过准备摘要确认，生成第一问后直接问答，主要考岗位知识和工程场景；正常完成覆盖所选主问题，每题最多两次追问，追问另计，可提前结束并复盘。
2. 综合面试与快速练习共用专业追问策略。根据候选人实际回答、已覆盖考点、缺口、矛盾和证据决定深挖、澄清或换题；正式问答过程中不纠错、不讲解、不泄露答案，结束后统一复盘。
3. 在原模型调用中增加有限诊断：已覆盖考点、原答依据、待核实缺口、下一步动作与简短理由。保存于本场会话，后续追问与复盘复用；问答中不展示，复盘可回查。
4. 首页、继续入口、统一历史和回放覆盖两类面试，显示业务类型；保留项目、简历场次与兼容入口。综合面试的四阶段、计时、资料、矩阵和复盘能力保持兼容。
5. 建立24例固定专业性回归资产：Java、Agent/RAG/工具调用、项目架构、异常边界各6例。案例、评分规则、运行器和策略摘要进入版本控制；原始日志留本地忽略目录。
