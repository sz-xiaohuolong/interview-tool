# AI 技术面试助手 V1 产品需求

Release ID：V1。Requirement Status：FROZEN。Open Questions：None。
依据：用户于 2026-10-15 提供的完整开发需求；产品范围已获批准，普通实现细节自主决定。

## 产品目标

面向个人本地使用的文本面试训练工具，支持 Java 后端、大模型应用 / Agent 开发和自定义岗位。围绕真实简历、项目和回答动态追问，结束后给出可核对依据的复盘。优先完整可用的闭环和 AI 质量。

## 冻结范围

1. 快速面试：岗位、实习生/初级/中高级、5/10/20 分钟目标时长、常规/压力风格、可选 JD。默认 Agent 开发、初级、10 分钟、常规。规划约 3/5/8 道主问题，每道最多两次追问，一次只问一题，面试中不泄露答案，可提前结束。
2. 简历押题：上传 PDF/DOCX/Markdown，解析并生成默认 10 题，包含简历依据、知识点、优先级、回答思路、进一步追问与风险。支持重新生成、从单题进入面试。明确为模型评估，不宣称真实公司命中率，缺失事实标记需要补充。
3. 项目面试：项目名称、简介、技术栈、职责等文本与 PDF/DOCX/Markdown/TXT 文档，可编辑、删除。问题覆盖 L1 整体理解、L2 实现细节、L3 场景权衡。资料快照提供依据，假设明确标识，资料不足时澄清。
4. 统一复盘：基本信息、完整对话、每题正确/错误/缺失/无法判断、推荐思路、知识解释、薄弱点与后续练习。技术准确性、理解深度、表达清晰度、追问应对各 0～4 分并说明依据。没有回答时不得伪造评价。
5. 资料管理：简历、项目、目标 JD 的新增、查看、修改、删除。文件和 SQLite 在本地持久保存。
6. 页面：首页真实统计与空状态、模式配置、面试工作台、历史与报告、资料管理。支持多行、快捷发送、加载和错误状态、防重、刷新恢复及未结束会话继续。

## 非目标

不做注册权限、支付、语音视频、GitHub 扫码、联网面经、Multi-Agent 框架、向量检索、复杂学习计划、社区、云部署与多用户服务。不引入 Redis、消息队列、微服务、Kubernetes。应用不部署公网；代码仓库同步按用户另行授权执行。

## 验收矩阵

| 编号 | 可测标准 |
|---|---|
| AC01 | 本机启动前后端，首页、资料、配置、工作台、报告与历史路径均可访问 |
| AC02 | 无资料创建快速面试，服务端按时长规划主问题；基于回答追问，最多两次后切题 |
| AC03 | PDF/DOCX/Markdown 简历上传，生成 10 道有依据的押题，重新生成与单题练习可用 |
| AC04 | 项目及多文档增改删，面试使用资料快照且涵盖 L1/L2/L3 |
| AC05 | 主动与自然结束后提供原始对话、有依据的逐题反馈和四维评分；薄弱项可重练 |
| AC06 | SQLite 持久保存；刷新、进程重启后可恢复会话、报告、资料和押题 |
| AC07 | 重复请求不重复记回答；过期页面提交、结束后回答均被拒绝；失败可重试 |
| AC08 | 缺失密钥、超时、限流、上游失败、非法 JSON/结构给出明确错误，不伪造成功 |
| AC09 | 文件类型、大小、空白内容、文本长度受限；截断可见；扫描 PDF 提示需文本资料 |
| AC10 | 文档视为不可信文本；不虚构实现、指标、职责；API 不向前端泄露密钥、内部决策和参考答案 |
| AC11 | README、自动化测试及可复现基础验收命令完整；真实模型与 Mock 证据分开记录 |

真实模型的相关性、追问意义与评估质量需要使用已配置的模型另外核验。Mock 自动化只验证编排、界面和持久化。
