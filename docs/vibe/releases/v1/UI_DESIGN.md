## 范围与设计选择

采用用户提供的浅色面试工具截图作为视觉参考，以冷色中性底、蓝色操作重点、浅色侧栏和紧凑工作区适配现有六页。保留原有品牌、文案、引导句、模式编号、页面入口和原生控件。

用户选择 Comp-led 路径，`.impeccable/config.json` 对应 `buildPath: comp`。参考图来自其他产品，按现有功能调整布局：概览页继续呈现练习入口、真实统计、最近练习与资料；会话页采用左侧对话、右侧信息栏。

参考图中的账户、会员、搜索、趋势图、虚构综合评分和首页对话功能均未纳入本次范围。全站采用浅色方案，不增加主题切换或新的存储键。

视觉取舍以低干扰和高频使用为主：操作页强调扫视效率与状态，内容页强调阅读层级，首页以克制引导突出主入口。色彩、字体、间距与动效的具体规则见根目录视觉规范。

## 页面方案

| 页面 | 表面模式 | 本次布局与阅读重点 |
|---|---|---|
| 练习概览 `/` | Persuade，受工具属性约束 | 左对齐引导；真实统计；三个横向、非等宽练习入口，快速面试为主操作；下方最近练习与资料 |
| 配置 `/configure/:mode` | Operate | 主表单与说明侧栏；保留原生选择框和表单顺序；提交动作清楚可见 |
| 简历押题结果 | Read | 题号、题目、依据与折叠思路分层；正文限制在 65～75ch；保留原生 details/summary |
| 面试 `/sessions/:id` | Operate | 左侧低干扰对话区与右侧紧凑信息栏；输入、发送、结束与重试状态清楚；原滚动容器保留 |
| 复盘 `/reports/:id` | Read | 摘要、四维评分、逐题分析、原始问答分层；长文自然换行，不裁切答案 |
| 资料库 `/materials` | Operate / 详情 Read | 清晰分类、资料清单、独立详情弹窗；长文件名与附件文本可读 |
| 历史 `/history` | Read | 行式列表；状态、时间、继续面试与复盘入口易扫读 |

会话页保留原 `ref="chat"` 与滚动职责。桌面对话记录高度为 `clamp(200px, calc(100dvh - 580px), 560px)`，为输入和发送区预留空间；窄屏恢复独立阅读区，元信息与输入操作继续可用。

## 面试复盘可读性调整（2026-10-16）

用户在 critique 评审和三份 CPA 候选稿后明确批准“选择 C，实施”。本轮采用 C 的评阅手册结构：逐题原答和分析作为主文，概览、评分和原有训练操作放在右侧。继承既有色板和系统中文字体，报告正文放大到20px、行高1.8，辅助说明16px。当前局部字号和断点统一维护在根目录 DESIGN.md，其他页面的15px正文保持。

修改限定 `frontend/src/pages/Report.vue`、`frontend/src/v2/V2App.vue`、`ReportTools.vue`、`SessionPracticeTools.vue` 的模板，以及新增 `frontend/src/styles/report.css`。四个Vue脚本原字节保持，原有数据、Props、条件、循环、事件、路由与存储职责保持。命名slot使实际阅读顺序与布局一致：主文、概览、整理复习、原题重练、完整对话。新增逐题分析、评分和建议为空时的展示提示，完整保留原始问答、分类、评分理由与依据。

批准图为 `.impeccable/mocks/report-20261016/C.png`，页面方向合同为 `.impeccable/surfaces/frontend-src-pages-report-vue.md`。图中的额外链接、折叠入口、错误导航选中状态及偏小字号不直接采用；实际问答和评分较长时自然延伸，不为追求图片位置删减内容。图片及精确提示词仅作设计证据，没有新增产品图片资产。

本轮直接沿用用户选定的C，没有运行随机概念轮，没有seed或独立QUALITY BAR卡，不补造对应记录。实际工程、浏览器、独立复判与Comp-led结果见 [验证记录第6节](VERIFICATION.md#6-面试复盘可读性调整验证2026-10-16)。正式Release仍为V1，V2人工验收状态保持。
