# Agent考点覆盖独立验收协议

这是V4追加考点目录与跨场练习的回归资产，行为范围见`docs/vibe/releases/v4/SPEC.md` AC15～24。原`evals/interview-agent/`的24例、其96次账本以及12个多轮剧本保持原协议，本目录不替代或借用它们。

## 首批六次选题

运行入口为`AgentTopicPilotLiveTest`，默认跳过，须显式设置`AGENT_TOPICS_LIVE_PILOT=true`。六类主题各运行一次真实PLAN，每次初级Agent应用工程师、三道主问题、单主题、空练习历史、无个人资料。问题对应的服务端考点和来源随输入完整归档；固定目录、Prompt及已加载构建的摘要用于识别实际被测策略。更改相关资产后，旧输出不能自动视为当前策略的验证。

真实调用总授权28次，首批上限6次，失败和中断也计数，不自动重试。运行器基于Git common-dir定位固定的`.evidence/agent-topic-coverage/ledger.json`与锁，不因切换工作树或输出路径重置额度。发送前持久化次数、合成输入、实际Prompt摘要、脱敏服务身份、模型和参数；响应保留原文、结构验证及实际Token，缺失用量标记未知。已有账本时拒绝覆盖或自动重跑。

首批只检查选题输出，不提交合成回答、不运行FOLLOWUP或REVIEW，不代表连续面试、跨场表现或专业性总体通过。结构检查只验证题量、来源引用与选定考点身份；是否实际考到能力、是否只是换措辞重复、是否泄露答案及依据是否充分，均须人工检查。人工结论留空，Agent不得代签。

## 人工确认后的两场

用户确认首批材料后，才可执行连续两场、每场三道主问题的真实快速练习；每场最多`1 PLAN + 9 FOLLOWUP + 1 REVIEW = 11`次，共最多22次，计入同一28次总账。首批运行器没有此阶段入口，不能通过环境变量绕过人工关卡。后续使用`AgentTopicContinuationLiveTest`，默认跳过，须显式设置`AGENT_TOPICS_LIVE_CONTINUATION=true`并使用Java21。固定合成回答见`continuation-answers.json`，每点三条，按实际考点和轮次提交，不临时改写回答。

续跑工具核对原六条有效PLAN、明确人工确认及批准材料摘要，复用同一个`pilot.lock`和账本，不支持失败后自动重跑或换目录重置。每次发送前保存输入、Prompt、参数及源码／已加载构建摘要；客户端和Service都通过后才发送下一请求。任一失败或生产降级立即停批，在途请求及用量保存后才关闭账本。软件回归覆盖批准、预算、顺序、落盘故障、Mock绕过、迟到请求及线程中断；不将预算视为必须花完的目标。

## 软件回归资产

- `AgentTopicCatalogTest`：目录与引用完整性、六类各至少10点、总计至少60点。
- `AgentPracticePlannerTest`：主题、近期10场与全部历史、轮换、复习数量确认、删除、Mock、旧数据和重启。
- `AgentPracticeIntegrationTest`：原服务接线、考点绑定、问答保密、追问继承、覆盖回顾和综合四阶段。
- `AgentTopicKnowledgeTest`与`AgentOfficialSourceBoundaryTest`：相关来源优先、混合主题分配和固定域名边界。
- 前端快速流程、报告行为测试及`agent-topics.spec.ts`：实际HTTP路径、开始前提示与原问定位。

运行软件测试不会隐式开启真实模型。原始证据留在忽略目录；公开结果只引用经过检查的合成材料和必要摘要。
